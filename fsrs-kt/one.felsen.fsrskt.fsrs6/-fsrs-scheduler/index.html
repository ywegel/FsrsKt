FsrsScheduler

class FsrsScheduler(val parameters: List<Double> = FsrsParameters.defaultParameters, val desiredRetention: Double = 0.9, learningSteps: List<Duration> = listOf(1.minutes, 10.minutes), relearningSteps: List<Duration> = listOf(10.minutes), val maximumInterval: Int = 36500, val enableFuzzing: Boolean = true, val dayCounter: FsrsDayCounter = FsrsDayCounter.WholeDays, val random: Random = Random.Default)

Schedules FsrsCards with learning steps, intervals from a desired retention and fuzz. A port of py-fsrs Scheduler, without the optimizer, serialization and card ids.

The scheduler never reads the clock: the time of a review is always passed in. It is immutable and can be shared, as long as random can be shared.

Deviations from py-fsrs:

  • The configuration is validated (see the exceptions below).

  • dayCounter makes the counting of elapsed days configurable. The default counts like py-fsrs.

  • Reviewing a card without memory state outside FsrsCardState.LEARNING, or in FsrsCardState.RELEARNING without step, throws an IllegalArgumentException instead of failing an assert. A card in FsrsCardState.LEARNING without step is treated as step 0, as the py-fsrs Card constructor does.

Throws

IllegalArgumentException

If any of the properties is out of its range.
