fun fuzzedInterval(intervalDays: Int, maximumInterval: Int, u: Double): Int

Fuzzes intervalDays with the given random value u, deterministically.

round(u * (last - first + 1) + first) over fuzzRange, bounded to at most maximumInterval. As in py-fsrs, the result can be one day above the range, if u is close to 1 and maximumInterval is large enough.

Return

The fuzzed interval in whole days. intervalDays itself, if it is below MIN_FUZZED_INTERVAL.

Parameters

intervalDays

The interval before fuzzing. (in whole days)

maximumInterval

The longest allowed interval. (in days, at least 1)

u

A uniformly distributed random value. (0.0 inclusive to 1.0 exclusive)

Throws

IllegalArgumentException

If maximumInterval is less than 1, or u is not in [0, 1).

fun fuzzedInterval(intervalDays: Int, maximumInterval: Int, random: Random): Int

Fuzzes intervalDays with a value drawn from random.

Draws exactly one Random.nextDouble if intervalDays is at least MIN_FUZZED_INTERVAL, and none otherwise, as py-fsrs does with random.random().

Return

The fuzzed interval in whole days, see fuzzedInterval.

Parameters

intervalDays

The interval before fuzzing. (in whole days)

maximumInterval

The longest allowed interval. (in days, at least 1)

random

The source of randomness. Pass a seeded Random for reproducible results.

Throws

IllegalArgumentException

If maximumInterval is less than 1.
