FsrsCard

data class FsrsCard(val state: FsrsCardState = FsrsCardState.LEARNING, val step: Int? = if (state == FsrsCardState.LEARNING) 0 else null, val stability: Double? = null, val difficulty: Double? = null, val due: Instant, val lastReview: Instant? = null)

An immutable flashcard as scheduled by FsrsScheduler. Same as py-fsrs Card, but without card_id: the app keeps track of which card this is.

A new card is FsrsCard(due = now): in FsrsCardState.LEARNING at step 0, without memory state and review.

Throws

IllegalArgumentException

If step is negative.

val step: Int?

The current learning or relearning step, as an index into FsrsScheduler.learningSteps or FsrsScheduler.relearningSteps. null in FsrsCardState.REVIEW. Defaults to 0 in FsrsCardState.LEARNING and to null otherwise. The step may be beyond the steps of the scheduler, if the card was scheduled with more steps before.
